# Mercury Map

PWA для полевых продаж: автозапись маршрута сейлера (9:00–18:00 по Ташкенту), метки партнёров со статусами,
лайв-контроль руководителя, заметки и комментарии, push-уведомления и отчёт дня.

## Роли
- **Сейлер** — маршрут пишется сам (в приложении или в фоне через OwnTracks), ставит метки партнёров, рисует вручную, отвечает на комментарии.
- **Руководитель** — видит команду в лайве, маршруты и метки всех сейлеров, оставляет заметки на карте и комментарии, смотрит отчёты.

## Переменные окружения (Vercel → Settings → Environment Variables)
| Переменная | Зачем |
|---|---|
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | Upstash Redis (добавляются автоматически при подключении базы) |
| `APP_PIN` | Код администратора — нужен, чтобы создавать аккаунты |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` | Push-уведомления (`npx web-push generate-vapid-keys`) |
| `CRON_SECRET` | Защита адреса ежедневного отчёта |
| `WORK_START`, `WORK_END` | Рабочие часы записи (по умолчанию 9 и 18) |

## API
`api/auth` — вход и аккаунты · `api/data` — партнёры и линии · `api/track` — GPS-трек ·
`api/owntracks` — приём точек из OwnTracks · `api/feed` — лайв, заметки, комментарии, подписки · `api/cron` — отчёт дня (18:05, пн–сб).
