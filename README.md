# Mercury Map

Веб-приложение (PWA) для ручной записи маршрута по Ташкенту и учёта партнёров.

- Рисование пройденного маршрута пальцем, история по дням, километраж
- Метки партнёров со статусами: отказался · жду ответа · жду документы · подключён
- Данные хранятся на устройстве (localStorage), есть экспорт/импорт копии
- Работает с экрана «Домой» на iPhone, просмотренные участки карты кэшируются

Стек: чистый HTML/CSS/JS + Leaflet, карты OpenStreetMap / CARTO / Esri. Сборка не нужна — Vercel отдаёт файлы как есть.
